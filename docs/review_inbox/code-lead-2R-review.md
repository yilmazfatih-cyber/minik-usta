## design-lead

- [CL-2R-20] [code-lead → design-lead] (Önemli) UX §5.8 (tek `rows`, "Açık yükseklik işareti `(rows + 2) − height`", örnek tablo) ↔ GDD K-49 (Hy, Hs ve `H = max(Hy, Hs + eMax)`): Tahtanın satır sayısı H'dir.
